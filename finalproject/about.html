Project Overview

This website was built for the WDD 231 final project. It demonstrates skills in HTML, CSS, and JavaScript including data fetching, DOM manipulation, and responsive design.

Features

  • Dynamic recipe data using Fetch API
  • Interactive modal popups for recipe details
  • Responsive layout for mobile and desktop
  • Form submission using URL parameters
  • Local storage and JavaScript interactions

Purpose

The goal of this website is to showcase popular Nigerian meals in a clean, interactive, and user-friendly way.
